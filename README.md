# Shorthand

Программа для скрытой передачи текста в изображениях PNG и BMP
(стеганография) с шифрованием по ГОСТ или лёгкой криптографией. Язык — Go,
интерфейс — Fyne. Научно-исследовательская работа, МГТУ им. Н. Э. Баумана,
кафедра ИУ10.

Версия 3 — новая схема, несовместимая с прежними версиями:

| | v2 (прежняя) | v3 |
|---|---|---|
| Изменение пикселя | замена 8 младших бит одного пикселя (3-2-3) | ±1, только там, где выгодно |
| Выбор мест | `math/rand` от числа из пароля | ключевая перестановка, STC по стоимостям HILL |
| Ключ | байты пароля | Argon2id + HKDF-Стрибог |
| Шифр | Кузнечик-MGM | Кузнечик-MGM, Ascon-AEAD128 или Магма-MGM |
| Сжатие | — | контекстная модель / deflate / 7 бит — лучшее |
| Исправление ошибок | — | код Рида–Соломона, 3 уровня |

Устройство и обоснование — [docs/DESIGN.md](docs/DESIGN.md), измерения —
[docs/EXPERIMENTS.md](docs/EXPERIMENTS.md).

## Использование

**Встраивание.** «Выбрать файл» — изображение PNG или BMP; ввести текст или
«Загрузить текст из файла» (UTF-8); при желании — имитозащищаемые данные
(не встраиваются, но без них сообщение не извлечь); пароль; шифр и
устойчивость; «Старт». По умолчанию результат сохраняется рядом с исходным
как `enc_<имя файла>` (существующие файлы не перезаписываются); другое место,
имя или формат (PNG/BMP по расширению) — «Куда сохранить…». Под полями
показано, сколько займёт сообщение.

**Извлечение.** «Выбрать файл», те же имитозащищаемые данные и пароль,
«Старт». Шифр и устойчивость программа определяет сама.

Изображение и текстовый файл можно перетащить на окно: они попадут на
открытую вкладку. Окно всегда в тёмной теме (акцент — зелёный логотипа вместо
синего: вкладка, поле в фокусе, выделение), по размеру содержимого; если
его растянуть, растут поля текста.

Важно:

- передавать только без сжатия с потерями: файлом, архивом, «как документ».
  JPEG, пересжатие мессенджером, масштаб, поворот и кадрирование уничтожают
  сообщение;
- прописные буквы извлекаются строчными;
- «обычная» устойчивость — наибольшая скрытность, но любое изменение
  картинки, кроме мелкого, портит сообщение; «повышенная» и «максимальная»
  переживают небольшую закраску и шум ценой большего числа изменений
  (цифры — в EXPERIMENTS.md).

Ветка `v3.1`: заголовок версии 4 (без битов, общих у разных сообщений;
запись через STC). Изображения, записанные веткой `v3`, читаются; прежние
сборки изображения новой версии не читают.

## Как выбрать изображение

От этого скрытность зависит не меньше, чем от алгоритма:

- **один контейнер — одно сообщение.** Два стегоизображения из одного
  исходника отличаются на ±1 в россыпи точек: это доказательство встраивания;
- **не брать картинку из интернета** и не использовать ту, что уже кому-то
  отправлена или опубликована: с оригиналом её можно сравнить;
- **удалять исходник** после встраивания (и из корзины, и из облака);
- лучше всего своя фотография с текстурой (листва, ткань, толпа). Плохие
  контейнеры: бывшие JPEG с заметным сжатием, снимки экрана, рисунки и
  фотографии с большими ровными областями (небо в пересвете);
- для скрытности — уровень «обычная»; «повышенная» и «максимальная» заметнее
  (EXPERIMENTS.md, разделы 1 и 6);
- сообщение короче — следов меньше: число изменений растёт с длиной текста;
- пароль длинный (фраза из нескольких слов): соль Argon2 общая для всех;
- имя файла по умолчанию `enc_…` лучше заменить обычным («Куда сохранить…»).

## Сборка

Нужны Go 1.26 и компилятор C (cgo, для Fyne; на Windows — MinGW-w64).

```bash
go build -ldflags "-H=windowsgui" -o shorthand.exe ./cmd/shorthand
```

Значок файла и описание встроены ресурсом `cmd/shorthand/resource_windows_amd64.syso`
(его подхватывает обычный `go build`). Собран из `icon.ico` и `versioninfo.json`
утилитой `goversioninfo` v1.4.1. В `icon.ico` все размеры (16–128 px) — исходный
рисунок `Samples/ico.ico` (`cmd/shorthand/icon.png`), уменьшенный фильтром
Катмулла–Рома (`golang.org/x/image/draw.CatmullRom`), 256 px — сам `icon.png`.
Упрощённый рисунок замка (`icon.go`) — только для значка в заголовке окна.
`fyne package` 2.4.3 с Go 1.26 не собирается. Пересоздать:

```bash
go run github.com/josephspurrier/goversioninfo/cmd/goversioninfo@v1.4.1 -64 -o resource_windows_amd64.syso versioninfo.json
```

Проверки:

```bash
go vet ./...
```

```bash
go test ./...
```

На GitHub те же проверки выполняет workflow «Проверки»
(`.github/workflows/test.yml`): задание `test` (Linux — ядро и стенд) и задание
`gui` (Windows — окно: `go vet`, тесты, сборка `shorthand.exe` и его SHA-256
артефактом). Dependabot раз в месяц предлагает обновления модулей и действий.

## Структура

| Путь | Что |
|---|---|
| `cmd/shorthand` | графический интерфейс |
| `cmd/stegobench` | эксперименты: стегоанализ, устойчивость, шифры, сжатие; встраивание для иллюстраций |
| `internal/alphabet` | 7-битный алфавит без регистра |
| `internal/compress` | сжатие: 7 бит, контекстная модель, deflate; корпус |
| `internal/crypto/kuznyechik`, `magma` | блочные шифры ГОСТ Р 34.12-2015 |
| `internal/crypto/ascon` | Ascon-AEAD128 и Ascon-XOF128 (NIST SP 800-232) |
| `internal/crypto/streebog` | хэш-функция ГОСТ Р 34.11-2012 |
| `internal/crypto/kdf`, `prng`, `suite` | ключи, генераторы, три режима |
| `internal/ecc/rs` | код Рида–Соломона с ошибками и стираниями |
| `internal/stego` | контейнер, перестановка, HILL, STC, формат v3 |
| `internal/analysis` | детекторы χ², RS, SPA, SPAM+ЛДФ; PSNR, SSIM |
| `internal/imageio` | чтение и запись PNG/BMP |
| `docs` | устройство и результаты экспериментов |

## Эксперименты

```bash
go run ./cmd/stegobench prepare -out data -src "C:/Windows/Web/Wallpaper/Theme1,C:/Windows/Web/Wallpaper/Theme2,C:/Windows/Web/Screen"
```

```bash
go run ./cmd/stegobench detect -data data/tiles -out results
```

```bash
go run ./cmd/stegobench robust -data data/full -out results
```

```bash
go run ./cmd/stegobench ciphers -out results
```

```bash
go run ./cmd/stegobench compress -out results
```

Фотографии для опытов в репозиторий не входят (обои Windows принадлежат
Microsoft): `prepare` готовит их из папок на компьютере.

Встроить случайную нагрузку одним из способов стенда (`v3`, `v3h`, `v3m` —
уровни v3; `pm1` — ±1 без STC; `report` — замена бита R/B; `v2` — 3-2-3) и
сохранить стегоизображение, например чтобы показать, где меняются пиксели:

```bash
go run ./cmd/stegobench embed -in photo.png -out stego.png -method v3 -rate 0.05
```
